PORTEX

Your PC games. Your Android.

PORTEX é um projeto de launcher Android com a proposta de permitir que usuários organizem, configurem e executem jogos originalmente desenvolvidos para PC em dispositivos Android.

Nosso objetivo é oferecer uma experiência simples, personalizável e otimizada para dispositivos móveis.

Status: Early Development
Plataforma: Android
Versão: 0.1 Preview

---

Sobre o projeto

O PORTEX busca combinar uma interface moderna com tecnologias de compatibilidade para execução de aplicações Windows no Android.

Funcionalidades planejadas

- Biblioteca personalizada de jogos.
- Importação de arquivos locais.
- Gerenciamento de ambientes de execução.
- Configurações gráficas individuais.
- Controles virtuais personalizáveis.
- Perfis de desempenho.
- Integração com tecnologias de compatibilidade Windows.

Tecnologias

- Kotlin
- Jetpack Compose
- Wine
- Box64
- DXVK
- VKD3D-Proton

Desenvolvimento

O projeto está em fase inicial. Nem todas as funcionalidades anunciadas estão implementadas.

Consulte nosso roadmap para acompanhar o desenvolvimento.

Requisitos

Os requisitos mínimos ainda estão sendo avaliados. Compatibilidade e desempenho dependerão do dispositivo, dos drivers e do jogo utilizado.

Aviso legal

PORTEX não distribui jogos comerciais. Os usuários devem utilizar arquivos de jogos que tenham direito de utilizar.

PORTEX é um projeto independente e não possui associação oficial com Microsoft, Wine, Box64 ou outros projetos de terceiros.

Comunidade

Relatórios de bugs, sugestões e contribuições serão bem-vindos através das ferramentas do GitHub.
